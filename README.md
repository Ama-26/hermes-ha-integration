# Hermes for HA — Home Assistant Integration

> ⚠️ **100% AI-generated** — This project and all its code are created entirely by AI (Hermes Agent). No human coding involved.

A native Home Assistant custom integration that connects [Hermes Agent](https://hermes-agent.nousresearch.com) as a first-class conversation agent, status sensor, and notification bridge — routing through any Hermes profile you configure.

## Features

- **Conversation Agent** — Registers as a HA Assist Pipeline agent. Voice commands are forwarded to the Hermes Gateway API and the response is spoken back via TTS.
- **Session Continuity** — Multi-turn conversations preserve context via `X-Hermes-Session-Id` headers.
- **Profile Routing** — Each config entry targets a specific Hermes profile. Use `default`, `voicepe`, `worker`, or any profile you've configured. Multiple entries supported.
- **Status Sensors** — `binary_sensor.hermes_connected` (gateway reachable), `sensor.hermes_latency` (last response time in ms), `sensor.hermes_model` (served model id).
- **UI Configuration** — Full config flow, no YAML required. Host, port, API key, profile — all configurable via Settings → Devices & Services.
- **Graceful Degradation** — Gateway down? Integration stays alive, marks unavailable, conversation agent returns a friendly error.

Tools execute **server-side** on the Hermes host — the integration is a thin HTTP client. No tool-call bridging needed.

## Requirements

- Home Assistant 2026.8.0+
- Hermes Agent with Gateway API Server enabled (`API_SERVER_ENABLED=true`, `API_SERVER_KEY` set)
- A Hermes profile configured (any model — the integration is model-agnostic)

## Installation

### Via HACS

1. Add this repository as a custom repository in HACS (category: Integration)
2. Install "Hermes for HA"
3. Restart Home Assistant
4. Go to Settings → Devices & Services → Add Integration → "Hermes for HA"
5. Enter your Hermes Gateway host, port, API key, and profile name

### Manual

1. Copy the `custom_components/hermes/` folder to your HA `custom_components/` directory
2. Restart Home Assistant
3. Configure via Settings → Devices & Services

## How It Works

1. User speaks to VoicePE → HA Assist Pipeline routes to `conversation.hermes`
2. Integration sends `POST /p/<profile>/v1/chat/completions` to the Hermes Gateway
3. Hermes processes the request on the configured profile (any model)
4. Tools (HA service calls) execute server-side via Hermes MCP
5. Text response returns → TTS → VoicePE speaks

Session continuity: the server returns `X-Hermes-Session-Id` on the first response. The integration sends it back on subsequent turns, restoring full conversation context.
